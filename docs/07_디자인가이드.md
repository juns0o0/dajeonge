# 다정이 디자인 가이드

디자인 원본은 `docs/design/`(디자인 확정본 핸드오프 패키지)이다. 값이 다르면 `web/index.html`(랜딩 완성본)과 `docs/design/DESIGN.md`·`tokens.css`가 이긴다. 레퍼런스 캡처는 `docs/design/desktop-full.png`(1280px)·`mobile-full.png`(390px)이며, 구현 화면은 같은 폭에서 픽셀 크기까지 동일하다.

## 토큰 (`web/assets/dajeong.css` `:root` = `docs/design/tokens.css`)
| 용도 | 값 |
| --- | --- |
| 글자·주 버튼·캐릭터 눈 | `#111111` |
| 페이지 바탕 / 카드 | `#F4F0EA` / `#FFFDFA` |
| 파스텔 4색 | 노랑 `#FFE59A` · 분홍 `#FFB5C1` · 민트 `#B7E1D1` · 하늘 `#A9D3FF` |
| 배지 | 평소 `#5BBE8E` · 관찰 `#F2B33D` · 확인 `#C2414F` |
| 보조 글자 | `#3C3934` · `#6B665E` · `#A39C90` |
| 선 / 입력칸 테두리 | `#ECE6DC` · `#F0EAE0` / `#D9D2C6` (1.5px) |
| 모서리 | 카드 28px · 안쪽 22px · 입력칸 10px · 버튼·칩 999px |
| 그림자 | 쓰지 않는다. 1.5px 선과 면 색으로 층을 나눈다 |

## 글꼴 (`web/fonts/`, 모두 SIL OFL)
- 제목·헤드라인: **Jua** 400 (`h1`, `h2`, 로고 글자).
- 본문: **Pretendard Variable** 14px/1.85 (앱 15px/1.6), 라벨 11px 800 대문자 자간 .1em.
- 외부 CDN 없이 자체 호스팅. `word-break: keep-all`.

## 캐릭터 (`web/assets/design/*.svg`, `web/assets/illus.js`)
- 비정형 덩어리(블롭) + 검정 타원 눈 두 개. 입은 없다. 사람·얼굴 사진을 쓰지 않는다.
- 로고 마크 = 검정 블롭 + 크림 눈, 다정이 아바타 = 노란 블롭 + 검정 눈. 태블릿에서 말할 때 노랑, 들을 때 하늘색.
- 눈 깜빡임(`blink` 5s)과 느린 둥실거림(`float` 6s)만 자동 반복. 나머지 움직임은 사용자 행동에 대한 반응. `prefers-reduced-motion`에서 전부 끈다.

## 화면별 적용
| 화면 | 적용 |
| --- | --- |
| 랜딩 `index.html` | 디자인 확정본 그대로. 바꾼 곳은 신청 폼 전송(`POST /api/applications`)과 ‘내용 보기’ → `/privacy.html` 링크 두 곳뿐 |
| 태블릿 `tablet.html` | 바탕 `#F4F0EA`, 아바타 노란 블롭, 큰 버튼 검정 알약 + 노란 글자 |
| 보호자 앱 `app.html` | 헤드라인 Jua, 카드 `#FFFDFA` 1.5px 선, 상태 카드 노랑, 배지 3색 |
| 백오피스 `admin.html` | 사이드바 검정 + 선택 메뉴 노랑, 표 위주 |

## 문구 규칙
- 합니다체. 다정이 대사만 자녀 말투(페르소나 설정).
- 배지는 평소 / 관찰 / 확인 · 기준 수집 중. 병명·진단·위험·점수·경고 표현은 쓰지 않는다.
- 랜딩 카피는 확정본 그대로 둔다. `[대괄호]` 자리표시자(비용·참여 조건·만든 사람들·이메일)는 발주사 확정값으로 채운다.
