# 다정이 MVP 검수 체크리스트 (검수조서 초안)

작업지시서 §6 검수 기준에 맞춰, **같은 대화 기록 1건**으로 음성 입력 → DB 저장 → 분석 → 대시보드 → AI 요약까지 확인한다.
캡처는 `docs/captures/결과보고서용/` 에 둔다 (56장, 검수용 가족 DEMO1 기준). 결과 열은 발주사 검수 시 채운다.

| No | 확인 항목 | 방법 | 기대 결과 | 결과 |
| --- | --- | --- | --- | --- |
| 1 | 태블릿 로그인 | `/tablet.html` 가족 코드 + 태블릿 비밀번호 | 대화 화면 진입, 잘못된 비밀번호는 오류 문구 | |
| 2 | 대화 시작 | 큰 버튼 클릭 | 다정이 첫마디가 음성으로 재생, DB `conversations` 1행 생성 | |
| 3 | 음성 입력 | 말하기 (Chrome, HTTPS) | 인식 텍스트가 화면에 표시되고 `turns`(parent) 저장 | |
| 4 | 텍스트 대체 | 마이크 거부 또는 ‘글로 말하기’ | 입력창으로 전환, 동일하게 저장 (`input_mode=text`) | |
| 5 | 가족 기록 반영 | 가족 이야기 키워드(예: 경로당)를 말함 | 응답에 해당 기록이 등장, 등록되지 않은 사실은 지어내지 않음 | |
| 6 | 대화 종료·분석 | ‘대화 마치기’ | `jobs(analyze)` → done, `conversation_metrics` 생성, 발화에 태그·응답 간격 기록 | |
| 7 | 대시보드 | 보호자 앱 홈 | 같은 대화가 ‘마지막 대화’에 보이고 최근 7일 지표에 반영 | |
| 8 | 대화 상세 | 대화 기록 › 해당 대화 | 지표 표 + 원문 + 태그(`repeat`/`uncertain`) + 응답 초 표시, 기록 ID 일치 | |
| 9 | AI 요약(대화) | ‘요약 만들기’ | `summaries` done, 문장에 병명·진단 표현 없음, 수치가 지표와 일치 | |
| 10 | AI 요약(주간) | 홈 › 이번 주 요약 만들기 | 최근 7일 기준 요약 생성, 기준선 미고정 시 비교 표현 없음 | |
| 11 | 기준선 | 시드 가족(DEMO1) | ‘평소’ 값 표시, 비교 배지(평소/관찰/확인) 표시 | |
| 12 | 기준선 미수집 | 새 가족으로 대화 1~2회 | ‘기준 수집 중 n/5회 · n/14일’ 표시, 비교 배지 없음 | |
| 13 | 다른 가족 접근 차단 | 다른 가족 토큰으로 `GET /api/conversations/{id}` | 404 | |
| 14 | 역할 제한 | 태블릿 토큰으로 `PUT /api/family/persona` | 403 | |
| 15 | API 실패 처리 | OpenAI 키를 틀리게 두고 대화 | 고정 문구로 대화 유지, `conversations.error` 기록, 요약 job은 failed → 재시도 가능 | |
| 16 | 빈 입력 | 빈 텍스트 전송 | 422 (저장 안 됨) | |
| 17 | 가족 정보 수정 | 페르소나·가족 이야기 추가/수정/삭제 | 저장 후 다음 대화에 반영 | |
| 18 | 대화 삭제 | 대화 상세 › 휴지통 | 대화·지표·음성 파일 삭제 | |
| 19 | 랜딩 신청 | 가정/기관 폼 제출 | 접수 메시지, 백오피스 ‘신청 접수’ 에 표시 | |
| 20 | 브라우저 | Chrome·Edge·Safari(PC), Android Chrome(태블릿), iOS Safari(보호자) | 레이아웃 깨짐 없음 (Safari 는 음성 인식 미지원 → 텍스트 대체) | |
