# 다정이 MVP 운영 매뉴얼

## 1. 실행

### 로컬 (개발·검수)
```bash
cd server
python3 -m pip install -r requirements.txt
cp ../.env.example ../.env            # OPENAI_API_KEY 등 채우기 (없으면 MOCK 모드)
python3 seed.py                       # 검수용 가족 DEMO1 (보호자 1234 / 태블릿 0000)
python3 -m uvicorn app.main:app --reload --port 8000
```
- 랜딩 `http://localhost:8000/` · 보호자 `…/app.html` · 태블릿 `…/tablet.html` · API 문서 `…/docs`

### 서버 1대 배포 (Docker)
```bash
cp .env.example .env && vi .env       # OPENAI_API_KEY, ADMIN_TOKEN, PASSWORD_SALT 필수
docker compose up -d --build
docker compose exec api python seed.py   # 필요 시
```
- 데이터는 `./server/data` 볼륨(SQLite DB + 음성 파일)에 남는다. 백업은 이 폴더를 복사하면 된다.
- HTTPS: 도메인을 붙인 리버스 프록시(Caddy 예시가 `docker-compose.yml` 주석에 있음)에서 종료한다.
- 규모가 커지면 `DATABASE_URL=postgresql+psycopg://...` 로 PostgreSQL 전환 (테이블은 자동 생성).

## 2. 환경변수 (.env)
| 이름 | 설명 | 기본 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 없으면 MOCK 모드(응답·요약을 규칙으로 생성) | 비움 |
| `OPENAI_CHAT_MODEL` | 응답·요약 모델 | gpt-4o-mini |
| `OPENAI_STT_MODEL` | 녹음 파일 변환 모델 | gpt-4o-mini-transcribe |
| `ADMIN_TOKEN` | 백오피스 로그인 토큰 · 연동 API 헤더 `X-Admin-Token` | admin-dev-token (반드시 변경) |
| `PASSWORD_SALT` | 비밀번호 해시 솔트 (변경 시 기존 비밀번호 무효) | 변경 필수 |
| `DATABASE_URL` | SQLAlchemy URL | sqlite:///./data/dajeong.db |
| `AUDIO_DIR` | 음성 파일 폴더 | ./data/audio |
| `CORS_ORIGINS` | 쉼표 구분 | * |
| `RUN_JOBS` | 작업 워커 실행 (0이면 끔) | 1 |

## 3. 가족 등록 (운영자)
백오피스 `https://<도메인>/admin.html` 에 운영자 토큰으로 들어가 ‘가족 → + 가족 등록’ 으로 등록한다. 기관 관리 도구 등 외부 시스템에서는 같은 API 를 호출한다.
```bash
curl -X POST https://<도메인>/api/admin/families -H "X-Admin-Token: $ADMIN_TOKEN" -H "content-type: application/json" -d '{
  "code":"FAM02","parent_name":"홍길순","parent_age":80,"region":"세종","guardian_name":"홍자녀","guardian_relation":"딸",
  "guardian_password":"비밀번호","tablet_password":"0000",
  "persona":{"display_name":"자녀이름","calls_parent":"엄마","formality":"반말","endings":[],"expressions":[],"personality":[],"habits":[],"avoid_topics":[],"family_notes":""}}'
```
가족 코드와 두 비밀번호를 보호자에게 전달한다. 페르소나·가족 이야기는 보호자가 앱에서 직접 수정할 수 있다.

## 4. 태블릿 설치
1. 안드로이드 태블릿 Chrome 에서 `https://<도메인>/tablet.html` 접속 → 가족 코드 + 태블릿 비밀번호.
2. 마이크 권한 허용. Chrome 메뉴 → ‘홈 화면에 추가’ → 전체화면으로 실행.
3. 화면 꺼짐 방지(설정 → 디스플레이)와 Wi-Fi 자동 연결 확인.
4. 음성 인식이 안 되는 환경(권한 거부, 구형 브라우저)은 ‘글로 말하기’로 전환된다.

## 5. 일상 점검
| 항목 | 방법 |
| --- | --- |
| 서버 상태 | `GET /api/health` (ai: mock/모델명) |
| 실패한 작업 | 보호자 앱 설정 탭, 또는 DB `jobs.status='failed'`. 재시도: `POST /api/jobs/{id}/retry` |
| API 사용량·오류 | 백오피스 ‘API 사용량’ 또는 `GET /api/admin/usage?days=30` → 사용자당 비용 산출 근거 |
| 신청 접수 | 백오피스 ‘신청 접수’ (상태·메모) 또는 `GET /api/admin/applications` |
| 가족 삭제·기록 내보내기 | 백오피스 가족 상세 → 삭제 / JSON 내보내기 (`DELETE`, `GET …/export`) |
| 로그 | `docker compose logs -f api` |

## 6. 개인정보·삭제 절차 (계약 §13)
- 대화 삭제: 보호자 앱 ‘대화 상세 › 휴지통’ → 대화·발화·지표·음성 파일 삭제.
- 가족 전체 삭제: DB에서 `families` 행 삭제 시 하위 기록이 함께 삭제됨(cascade). 음성 파일은 `data/audio/fam<id>_*` 를 지운다.
- 음성 보관 기간: 가족별 `keep_audio_days`. 기간 지난 파일 정리:
  ```bash
  cd server && python3 -c "from scripts_cleanup import purge_audio; purge_audio()"
  ```
  (`server/scripts_cleanup.py` 참고, cron 으로 하루 1회 실행 권장)
- 외부 전송: OpenAI 에는 대화 텍스트·페르소나·가족 기록만 보내고 이름·연락처·가족 코드는 보내지 않는다.

## 7. 장애 대응
| 증상 | 조치 |
| --- | --- |
| 다정이가 “잠깐만, 다시 말할게”만 반복 | OpenAI 키·잔액·네트워크 확인. `conversations.error` 에 원인 기록됨 |
| 대화가 ‘분석 중’에서 멈춤 | 워커 실행 여부(`RUN_JOBS=1`) 확인, `jobs` 표에서 failed 재시도 |
| 요약 실패 | `summaries.error` 확인. MOCK 모드면 키 설정 |
| 태블릿이 안 들음 | 마이크 권한, Chrome 인지, HTTPS 인지(HTTP 에서는 음성 인식이 막힘) |
