# 다정이 MVP 기능명세서

- 과업: AI Care Bot ‘다정이’ 웹 MVP 설계·디자인·개발 용역 (작업지시서 R4, 2026.11.04)
- 발주: 인하우스앤파트너스(주) · 수행: 펄스픽시아
- 버전: 1.0 (납품본) · 변경 이력은 문서 끝

## 1. 사용자와 화면

| 사용자 | 화면 | 경로 | 기기 |
| --- | --- | --- | --- |
| 방문자 | 랜딩페이지 | `/` | PC·모바일 |
| 부모님 | 태블릿 대화 화면 | `/tablet.html` | 안드로이드 태블릿 Chrome (전체화면·홈 화면 추가) |
| 보호자(자녀) | 보호자 앱 | `/app.html` | 휴대폰 브라우저 (홈 화면 추가 시 앱처럼 동작) |
| 운영자 | 백오피스(데이터 관리) · 연동 API | `/admin.html`, `/api/admin/*`, `/docs` | PC |

로그인은 **가족 코드 + 비밀번호** 1쌍씩(보호자용·태블릿용)이다. 모든 기록은 가족 단위로 격리되며, 다른 가족의 대화 ID로 접근하면 404를 돌려준다.

## 2. 기능 목록

### F1. 음성 대화와 저장 (태블릿)
| ID | 기능 | 동작 | 예외 |
| --- | --- | --- | --- |
| F1-1 | 태블릿 연결 | 가족 코드 + 태블릿 비밀번호로 로그인, 토큰을 기기에 저장 | 코드·비밀번호 오류 시 메시지 표시 |
| F1-2 | 대화 시작 | 큰 버튼 1개. 누르면 대화가 생성되고 다정이가 첫마디를 음성으로 말함 | 페르소나 미등록 시 “보호자 앱에서 먼저 등록” 안내 |
| F1-3 | 음성 입력 | 브라우저 음성 인식(Web Speech API, ko-KR)으로 부모님 말을 글자로 변환. 다정이 발화가 끝나면 자동으로 듣기 시작 | 미지원·권한 거부 시 텍스트 입력으로 전환(‘글로 말하기’) |
| F1-4 | 응답 생성 | 부모 발화 저장 → 페르소나 + 관련 가족 기록만 골라 LLM 응답 생성 → 저장 → 브라우저 기본 TTS로 재생 | LLM 실패 시 고정 문구(“잠깐만, 다시 말할게”)로 대화 유지, 오류를 대화에 기록 |
| F1-5 | 시간 기록 | 다정이 발화 재생 종료 시각, 부모 발화 시작·종료 시각을 함께 저장 (응답 간격 계산용) | 시각 누락 시 서버 시각으로 대체 |
| F1-6 | 대화 종료 | ‘대화 마치기’ 또는 3분 무응답 시 종료 → 분석 작업 큐 등록 | 저장 실패 시 화면에 오류 표시, 재시도 안내 |
| F1-7 | 녹음 파일 변환(보조) | `POST /conversations/{id}/audio` 로 파일 업로드 → 서버 STT(OpenAI) | MOCK 모드·25MB 초과 시 오류 |

### F2. 대화 분류와 지표 (서버 작업)
| ID | 기능 | 동작 |
| --- | --- | --- |
| F2-1 | 발화 정리 | 부모 발화마다 공백 제외 글자 수, 직전 다정이 발화 종료 → 발화 시작 간격(초) 계산 |
| F2-2 | 태그 분류 | `repeat`(같은 대화 안 앞선 발화와 글자 2-gram 유사도 ≥ 0.7), `uncertain`(‘글쎄’, ‘기억이 안’, ‘모르겠’ 등 패턴) |
| F2-3 | 대화 지표 | 발화 길이 평균, 동일 표현 반복률, 불확실 표현 비율, 응답 간격 평균(2분 초과는 제외), 대화 참여(부모 글자 수 비중), 대화 시간 |
| F2-4 | 유효 대화 | 부모 발화 3회 이상이면 유효. 기준선 계산에는 유효 대화만 사용 |
| F2-5 | 개인 기준선 | 첫 유효 대화 후 14일 경과 + 유효 대화 5회 이상이면 초기 14일 구간의 평균·표준편차로 고정. 한 번 고정되면 바꾸지 않음 |
| F2-6 | 비교 | 최근 7일 평균을 기준선과 비교해 `same`=평소(1편차 미만) / `watch`=관찰(1편차 이상) / `notable`=확인(1.5편차 이상). 의료 판정 아님 |
| F2-7 | 작업 큐 | 분석·요약은 Job 테이블에 쌓여 뒤에서 처리. 실패 시 상태·오류 저장, 3회까지 자동 재시도, 보호자가 수동 재시도 가능 |

| F3-4 | 대화 기록 | 월별 목록 → 상세(지표 표, 발화별 태그·응답 간격·입력 방식, 원문) |

| F3-10 | 설정 | 태블릿 연결 안내, 처리 작업 목록·재시도, 개인정보 안내, 로그아웃 |

### F5. 운영·보안 (계약 §13)
- HTTPS는 배포 환경(리버스 프록시)에서 적용. API 키는 서버 환경변수로만 보관.
- 외부 API 호출마다 `api_usage` 에 목적·토큰·성공 여부 기록. `GET /api/admin/usage` 로 집계.
- 음성 파일 보관 일수는 가족별 `keep_audio_days`(기본 30일). 삭제 배치는 운영 매뉴얼의 명령으로 실행.

### F6. 백오피스와 연동 API (운영자)
운영자 토큰(`X-Admin-Token`)으로 쓰는 PC 화면 `/admin.html`. 가족 경계 없이 모든 데이터를 조회·관리하며, 같은 API 를 외부 시스템(기관 관리 도구, 알림 발송 등)이 그대로 호출한다. 전체 명세는 `/docs`.

| ID | 기능 | 동작 | API |
| --- | --- | --- | --- |
| F6-1 | 토큰 로그인 | 운영자 토큰 입력 → 탭 세션에만 보관. 틀리면 “토큰이 맞지 않습니다” | `GET /api/admin/stats` (검증) |
| F6-2 | 현황 | 등록 가족·대화·신규 신청·실패 작업 수, 최근 작업, 연락 전 신청, 외부 API 호출 수 | `GET /api/admin/stats` |
| F6-3 | 가족 목록·등록 | 코드·이름 검색, 가족 등록(코드·부모님·보호자·비밀번호 2종) | `GET/POST /api/admin/families` |
| F6-4 | 가족 상세 | 가족 정보·페르소나·가족 이야기·개인 기준선(평균·편차)·최근 대화 30·작업 20. 정보 수정, 비밀번호 재설정 | `GET/PUT /api/admin/families/{id}` |
| F6-5 | 가족 삭제 | 코드 재입력 확인 후 대화·발화·지표·기준선·요약·작업·세션·음성 파일 일괄 삭제 | `DELETE /api/admin/families/{id}` |
| F6-6 | 기록 내보내기 | 가족 1곳의 전체 기록(가족·이야기·기준선·대화+발화+지표·요약)을 JSON 파일로 저장 | `GET /api/admin/families/{id}/export` |
| F6-7 | 대화 기록 | 모든 가족의 대화를 가족·상태로 걸러 지표와 함께 표시 → 상세(원문·태그·응답 간격) | `GET /api/admin/conversations[/{id}]` |
| F6-8 | 신청 접수 | 랜딩 신청 목록, 상태 변경(신규·연락함·완료), 메모 | `GET/PUT /api/admin/applications` |
| F6-9 | 처리 작업 | 분석·요약 작업 목록(상태·시도·오류), 실패 작업 다시 시도 | `GET /api/admin/jobs`, `POST …/retry` |
| F6-10 | API 사용량 | 최근 30일 목적별 호출·오류·토큰 집계, 최근 호출 50건 | `GET /api/admin/usage[/log]` |
| F6-11 | 연동 안내 | 인증 방법, 엔드포인트 표, 기관 도구 연동 순서와 요청 예시 | 화면 안내 |

## 3. 이번 범위 밖 (설계만)
기억 회상 정답률·일관성 점수·음성 감정·자동 알림·예약 리포트·자녀 음성 복제·다중 화자 분리. ERD의 `reserved_*` 컬럼이 연결 위치다.
