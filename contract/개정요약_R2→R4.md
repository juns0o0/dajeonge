# 계약 문서 개정 요약 (R2 → R4, 2026-11-07 최종본)

발주사(김현정 담당)와 “서버·DB 1식은 수정하면서 작업” 하기로 합의한 내용을 문서에 반영했다. **금액(₩7,000,000, 21.5 M/D)·지급 조건·산출물 종류는 그대로**이고, 바뀐 것은 아래 세 가지다.

| 구분 | R2 (10/28) | R4 (11/7) | 이유 |
| --- | --- | --- | --- |
| 착수·기간 | 2026.10.08 ~ 11.13 | **2026.10.13 ~ 11.13** (5주, 협의 조정 가능) | 착수일을 10.13 으로 조정, 주차별 일정표도 같이 조정 (11.07 최종 확인) |
| 음성 입력 | “음성 입력 → STT → 응답 → TTS” | **브라우저 음성 인식(Web Speech API, Chrome) + 기본 TTS**, 미지원 환경은 텍스트 입력 대체. 서버 STT(OpenAI)는 녹음 파일 업로드용 보조 | 실시간 서버 STT 스트리밍은 5주·700만 원 범위에서 무리. 브라우저 인식이 안정적이고 비용 0 |
| 서버·DB | “웹앱·서버·DB 1식” | **연동 API + DB + 데이터 관리 백오피스**. 저장·조회 기능은 외부 시스템(기관 관리 도구 등)이 연결할 수 있는 API 형태로 제공하고, 운영자가 가족·대화·신청·작업·API 사용량을 관리하는 백오피스를 포함. 등록 가정 30개 이내 | 서버 구성 설명 대신 “연결할 수 있는 API” 와 “관리 화면” 으로 산출물을 정의. 랜딩페이지 기획·디자인은 그대로 |

| 랜딩페이지 | “소개·사용 방법·화면 예시·신청폼” | **갑이 확정한 디자인 시안을 그대로 구현** (소개 → 태블릿 → 한 주 안부 → 작동 방식 → 자녀 앱 → 이용 전후 → 모집 → 진행 과정 → 신청 → FAQ → 만든 사람들), 신청폼은 사전 신청자 DB(구글 시트)·신청자 확인 화면 → 서버 배포 후 백오피스 연결, 공개 주소(GitHub Pages), 1280px·390px 캡처 대조 | 디자인 확정본(11/7) 기준으로 범위를 적고, 서버 없이도 신청을 받을 수 있게 저장 방식을 명시 |
| 산출물·자료 | 점검 결과·캡처·운영 매뉴얼, 소스·계정 | 기능명세(문서·엑셀)·흐름도·ERD·정보구조도·시스템 구조도·API 문서·디자인 사양 / 검수 체크리스트·캡처·운영 매뉴얼·**결과보고서**, **GitHub 저장소** 인수인계 | 실제 만든 문서 목록과 납품 방식에 맞춤 |

문서별 바뀐 문장
- **견적서**: 견적번호 PX-20261107-R4, 견적일자 11/7, 직무 설명(디자인 확정본 구현·결과보고서), 용역기간, 최종 산출물 문구(연동 API·DB 1식 + 데이터 관리 백오피스 1식), 공수 항목 설명(백오피스·연동 API), “세부 범위” 주석.
- **계약서**: 제2조 기간, 제3조 음성 대화 항목(연동 API 형태) + 데이터 관리 백오피스 항목 추가 + 랜딩(디자인 시안 기준) + 최종 산출물(결과보고서·GitHub), 제6조 자료 제공(디자인 시안·확정 문구), 제7조 검수(백오피스 확인), 제13조 운영 범위.
- **작업지시서**: 과업기간, §1 목적(연동 API·백오피스), §2 [1단계] 제목·2개 항목(연동 API), [3단계] 제목·백오피스 항목 추가·기준선 ‘수집 중’ 표시, §4 산출물(연동 API 1식 + 백오피스 1식), §5 일정표 날짜·2주/4주 작업 내용, §6 검수 방법(백오피스 확인), [4단계] 랜딩 항목(디자인 시안·백오피스 연결), §4 산출물 목록 구체화, §8 발주자 준비 사항(디자인 시안·확정 문구), 하단 개정 표시.

변경하지 않은 것: 공수·단가·합계, 지급 조건(50/50), 검수·하자보수 30일, 제외 범위(§7/§9), 별도 실비 조항, 서명란(사업자 정보).
